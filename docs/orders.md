# Orders

## Checking order status
Order status (placed, shipped, delivered) can be checked by looking up the
order ID. Use the order lookup tool to get real-time status and ETA.

## Cancelling an order
Orders can be cancelled within 1 hour of placement from the Orders page.
After that window, the order has already entered fulfillment and cannot
be cancelled, but it can be returned once delivered.

## Order not showing up
If a recent order isn't showing in your order history, wait up to 15
minutes for it to sync, then contact support if it still doesn't appear.
